# ForumX

A Reddit-inspired social discussion platform built from scratch.

## Purpose

ForumX is a long-term engineering project for learning and implementing:

- Backend development
- Database design
- REST APIs
- Authentication
- Community systems
- Voting systems
- Feed ranking
- Caching
- Distributed systems
- Scalability
- System design

## Current Status

Project foundation.
